## 💼 Tentang Project

**Demo Web UMKM** adalah website profil profesional untuk bisnis rental motor di Yogyakarta. Project ini dirancang untuk menampilkan informasi bisnis, katalog kendaraan, dan memudahkan pelanggan untuk melakukan kontak serta pemesanan.

Dibuat sebagai showcase website modern yang responsif, cepat, dan user-friendly.

---

## ✨ Fitur Utama

- ✅ **Desain Responsif** - Tampil sempurna di semua ukuran layar
- ✅ **Performance Optimal** - Dibangun dengan Vite untuk kecepatan maksimal
- ✅ **Component-based** - Vue 3 dengan Composition API
- ✅ **Styling Modern** - Tailwind CSS untuk design yang elegan
- ✅ **SEO Friendly** - Struktur HTML yang baik untuk SEO
- ✅ **Fast Load Time** - Optimisasi aset dan lazy loading

---

## 🛠️ Tech Stack

### Frontend Framework
- **Vue 3** (v3.5.34) - Progressive JavaScript framework
- **Vite** (v8.0.12) - Next generation frontend tooling

### Styling
- **Tailwind CSS** (v4.3.0) - Utility-first CSS framework
- **PostCSS** (v8.5.15) - Tool for transforming CSS
- **Autoprefixer** (v10.5.0) - Parse CSS and add vendor prefixes

### Build Tools
- **@vitejs/plugin-vue** (v6.0.6) - Official Vue plugin for Vite
- **@tailwindcss/vite** (v4.3.0) - Vite plugin for Tailwind CSS

### Deployment
- Deployed di **Vercel** untuk automatic deployment dan hosting

## 🚀 Instalasi

### Prerequisites
- Node.js (v16 atau lebih tinggi)
- npm atau yarn package manager

### Langkah-langkah

1. **Clone repository**
```bash
git clone https://github.com/joyadrnsyh/demo-web-umkm.git
cd demo-web-umkm
```

2. **Install dependencies**
```bash
npm install
# atau jika menggunakan yarn
yarn install
```

3. **Jalankan development server**
```bash
npm run dev
# atau
yarn dev
```

Website akan terbuka di `http://localhost:5173`

## 💻 Penggunaan

### Development Commands

```bash
# Start development server dengan hot reload
npm run dev

# Build untuk production
npm run build

# Preview build production secara lokal
npm run preview
```

### Project Scripts
- `dev` - Jalankan Vite development server
- `build` - Build project untuk production
- `preview` - Preview hasil build secara lokal

## 🔨 Build & Deploy

### Build untuk Production
```bash

```

Output akan disimpan di folder `dist/`

### Deploy ke Vercel

Project ini sudah dikonfigurasi untuk deploy otomatis di Vercel. Setiap kali ada push ke branch `main`, Vercel akan otomatis build dan deploy website.
